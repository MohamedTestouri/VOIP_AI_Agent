description: Design and execute test plans for software and VoIP protocol behavior.
---
Create positive, negative, boundary, timeout, retry, concurrency, interoperability, and regression cases. Use sanitized SIP/SDP and provisioning fixtures with expected results. Cover exact phone model and firmware separately. Distinguish tests written, tests executed, and tests blocked. Preserve reproduction steps and environment metadata; never test on live telephony without authorization.
