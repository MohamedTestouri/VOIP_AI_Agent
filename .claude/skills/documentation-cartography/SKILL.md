# Documentation and cartography

Create a component diagram, use-case map, sequence diagrams for critical features, API inventory, database ER map, event/queue/job map, provisioning flow, and deployment view where evidence exists. Attach each important node/edge to code/config references and tests. Use `UNKNOWN` or a gap list instead of guessing. Update diagrams with code changes; validate Mermaid syntax and ensure no secrets or customer data are embedded.
